The Last Fork

A full-stack web application connecting restaurants with surplus food to customers at reduced prices, incorporating gamification through leaderboards, badges and environmental impact statistics such as estimated CO₂ saved from landfill. As the team’s DevOps lead, I designed and implemented the CI/CD pipelines for a microservice-based architecture, deploying applications to a Kubernetes (k3s) cluster with automated, zero-downtime rolling deployments, readiness and health checks. Configured supporting infrastructure including PostgreSQL, Apache Kafka, reverse proxying, load balancing, automatic TLS certificate renewal and horizontal scaling. Beyond DevOps, contributed to backend API development, pull request reviews and bug fixes, while developing additional frontend pages and backend endpoints to meet project requirements. Coordinated weekly team meetings for an eight-person team, tracked project progress, and produced comprehensive deployment documentation enabling the entire platform to be deployed to a Linux server, and a development guide which included tips for continued development and common issues and how they were overcome as well as a comprehensive testing guide.
